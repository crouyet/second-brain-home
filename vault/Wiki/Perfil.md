# Perfil — quién soy (EJEMPLO — reemplazá con el tuyo)

> Esto es un ejemplo ficticio para que veas la forma. El sistema lee este doc para adaptar
> el tono y las decisiones. Borrá todo y escribí el tuyo.

## Persona (ejemplo: "Alex")
- Trabaja en algo creativo + tiene un proyecto propio en marcha.
- **Cómo funciona:** arranca con mucha energía y le cuesta cerrar (tipo TDAH). Necesita que
  el sistema decida por ella, no que le pregunte. Una acción física a la vez.
- **Qué la abruma:** la hoja en blanco, las listas largas, el reproche.
- **Qué la motiva:** ver progreso concreto, wins chicos, que el sistema "la lea".

## Cómo trabajar conmigo
- **Cero reproche, siempre.** Si ayer no pasó nada, hoy arranca de cero.
- Máximo 3 tareas al día. Nada entra sin próxima acción física clara.
- Predecí mi energía, no me la preguntes.
- En días de poca energía: primero el cuerpo, después UNA cosa chica.

## North star (ejemplo)
- Sacar la carga mental de lo mundano para tener cabeza para lo que importa.
