# Rutinas de casa (EJEMPLO — editá con las tuyas)

El tick de la mañana lee este doc para recordarte "lo que toca hoy". Cada rutina tiene una
frecuencia y un `last_done` (última vez hecha); si se pasó, aparece como vencida.

## Ritmo semanal (ejemplo)
- **Lunes** — planificar la semana
- **Martes** — prep de comida (bajar del freezer lo del miércoles)
- **Miércoles** — limpieza profunda + lavado de ropa
- **Jueves** — orden / ropa
- **Domingo** — meal prep del finde

## Rutinas con frecuencia
| Rutina | Frecuencia | last_done |
|---|---|---|
| Lavar sábanas | cada 2 semanas | 2026-01-01 |
| Regar plantas | cada 3 días | 2026-01-01 |
| Limpieza profunda | semanal | 2026-01-01 |

*(Actualizá `last_done` cuando la hagas — o dejá que el sistema lo marque.)*
